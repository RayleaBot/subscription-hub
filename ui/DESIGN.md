# Design System: Subscription Hub

## Overview

**Creative North Star: "雾白·青瓷"**

本页继承 RayleaBot 的中性表面、少量青瓷主操作与紧凑排版。账号和订阅分别以混合平台卡片呈现，搜索、筛选和操作位于首屏；身份、实际状态和下一步操作构成阅读顺序。页面标题保留给辅助技术，不重复宿主的大顶栏。

共享视觉语义以 RayleaBot 根目录的 `PRODUCT.md`、`DESIGN.md` 为准。本文件只记录插件的应用方式；运行时颜色与组件细节以 [styles.css](src/styles.css)、[ThemeProvider.vue](src/components/ThemeProvider.vue) 和各组件为准，不另维护全局 token 表。

## Colors

画布、卡片、搜索和选中筛选使用中性色；青瓷用于主按钮、开关和少量选中标记。成功、警告和错误必须同时附有文字，平台图标保留各自识别色。

宿主主题变量映射到插件语义变量，Ant Design Vue 浮层随主题同步。主按钮前景使用 `--on-accent`，亮色为白色，暗色为深青瓷；不要把亮色按钮的白字直接用于暗色主按钮。调整主题或配色时，分别检查亮暗模式及默认、悬停和焦点状态的文字与控件对比度。

## Typography

正文使用本机中文无衬线字体栈，基础字号（14px）、行高（1.5）；卡片身份标题（16px），筛选与表单辅助内容（12–13px），时间和次要计数（11px）。账号标识与计数使用等宽数字，长名称截断并保留完整提示，错误说明允许换行。

字体不依赖远程下载。页面样式优先 HarmonyOS Sans SC、PingFang SC、Noto Sans SC 等本机字体；Ant Design Vue 控件使用 Segoe UI、Microsoft YaHei UI 的本机回退。

## Layout

页面最大宽度（1760px），桌面内边距（24px 28px）。工具行依次安排搜索和主要操作，下方为可换行的平台、状态筛选与结果说明；平台不拆成重复分区。

账号网格最小列宽（320px）、间距（18px），订阅网格最小列宽（340px）、间距（12px）；窄屏缩为单列。工具行在（820px）以下纵向排列，手机页面边距（16px）。触屏或（600px）以下，主要按钮、筛选和搜索至少（44px）高。

设置、账号新增与编辑、扫码、删除确认及解析对象选择均使用居中 Modal，不使用侧栏弹出。订阅卡片编辑在集合内展开，详细目标选择保留在该编辑区。订阅和解析的保存栏在桌面贴近视口底部，手机进入正常文档流。

## Elevation & Depth

集合使用实底、细边框与留白建立层次；卡片悬停仅加强边框，不抬升或放大。保存栏与标准 Modal 使用阴影区分浮层，避免给每张卡片叠加阴影或玻璃效果。

## Shapes

账号卡片圆角（14px），订阅卡片沿用（12px）；卡片内边距桌面（20px）、手机（18px）。常规按钮圆角（10px），筛选（8px），搜索（9px）。头像为圆形，平台识别图使用小幅圆角和白色底，亮暗主题保持标志可辨认。

## Components

- **集合与筛选：** 账号支持文本、平台及状态组合筛选，订阅增加推送类型筛选。筛选按钮通过 `aria-pressed` 表达选中状态；空结果提供清除筛选入口。账号先完整读取服务端分页，再筛选、排序并按每页 20 项展示；这些内容是可刷新、可丢弃的视图，业务状态仍来自服务端。
- **账号卡片：** 平台和启用状态在上方，头像与身份居中，凭据状态、错误和检查时间依次排列，检查、重新登录与编辑操作在底部。凭据失效或存在检查错误的账号优先展示；平台风控错误保留实际说明，不据此推断 CK 已失效。
- **订阅卡片：** 显示平台、对象身份、推送类型、目标和订阅人摘要。编辑区的“完成”结束当前编辑，页面“保存设置”才提交变更；未保存提示始终说明这个边界。实现见 [SubscriptionCard.vue](src/components/SubscriptionCard.vue) 与 [App.vue](src/App.vue)。
- **Modal 与表单：** 使用 Ant Design Vue 的标准居中对话框和主题映射，长内容在弹窗内滚动。账号表单、扫码和设置见 [AccountManager.vue](src/components/AccountManager.vue)，解析目标选择见 [ResolverSettingsPanel.vue](src/components/ResolverSettingsPanel.vue)。保留 Esc 关闭、关闭后焦点返回、控件标签与可见焦点。
- **账号操作反馈：** 登录成功及账号保存、添加、删除、设置保存和检查完成使用 Ant Design Vue toast 轻提示，显示（3 秒）后自动消失；复用同一提示位置，不堆叠成功消息，不保留整行成功提示。检查错误仍显示可关闭的错误状态条，卡片保留服务端返回的具体错误。
- **动效与反馈：** 按钮颜色过渡（160ms）；集合重排位移（220ms）、进入与退出透明度（180ms），仅使用轻微纵向位移。加载操作显示忙碌状态；尊重 `prefers-reduced-motion`，不承诺未经测量的帧率。
- **平台与操作图标：** [PlatformLogo.vue](src/components/PlatformLogo.vue) 使用本地生成的 Bilibili、抖音、微博、网易云音乐 PNG，并搭配平台名称；图片为装饰性空替代文本。生成来源和原始提示词见 [provenance.json](src/assets/platforms/provenance.json)，不将生成图称为官方素材。操作图标由 [UiIcon.vue](src/components/UiIcon.vue) 提供，头像加载失败显示文字回退。

修改后按影响验证组件行为、Vue 类型检查和生产构建；视觉与交互检查覆盖桌面、窄屏、亮暗主题、Esc 关闭、焦点返回及 reduced-motion。组件测试应覆盖成功 toast 与错误状态条的区别、筛选和显式保存边界。预览数据必须标注“演示”；模拟宿主与组件测试不能替代真实平台扫码登录、账号保存及服务端状态读回的联调，联调结果和性能数据应单独记录。

## Do's and Don'ts

- **Do** 先呈现可搜索的对象集合，再按需进入设置；以明确文本区分凭据状态、检查错误和未保存修改。
- **Do** 保持亮暗主题的相同信息顺序、操作能力、键盘焦点和触屏目标尺寸。
- **Don't** 添加重复大标题、全宽折叠设置区、侧栏弹出或按平台重复的卡片分区。
- **Don't** 用颜色独自表达状态，或把本地草稿、演示数据和平台风控提示当作正式服务端状态。
